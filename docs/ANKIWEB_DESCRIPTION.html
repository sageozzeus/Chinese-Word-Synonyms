Shows synonyms from your own collection while you review Chinese cards: other notes whose Meaning / Definition / English field normalizes to the same sense as the card you are on.

Example: reviewing 快乐 (meaning happy) → on the answer you may see 高兴, 开心, 愉快 if those cards exist with the same normalized meaning.

Features

  • Offline — indexes your collection after Rebuild Index; no dictionary, CEDICT, or AnkiConnect
  • Synonyms panel on the card back (default); optional count on the question (e.g. 1 Synonym)
  • Click a synonym to open that note in the Browser
  • Tools → Chinese Word Synonyms… — decks, fields, limits, colors, optional custom CSS
  • Works alongside Chinese Character Relations (shared characters vs shared meanings)

Requirements

  • Anki Desktop 23.10+ (macOS, Windows, or Linux)
  • Notes with a Word/Hanzi field and a Meaning (or Definition / English) field

Setup

  1. Install and restart Anki
  2. Tools → Chinese Word Synonyms…
  3. General: set Word and Meaning fields → Rebuild Index
  4. Review a card whose meaning matches another note
