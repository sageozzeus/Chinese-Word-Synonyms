Shows synonyms from your own collection while you review Chinese cards: other notes that share a normalized Meaning / Definition / English sense.

Example: reviewing 快乐 (happy) → front shows 2 Known Synonyms / 6 Total Synonyms; back lists 高兴, 开心, 愉快 when those notes share a sense.

Features

  • Offline — indexes your collection after Rebuild Index; no dictionary, CEDICT, or AnkiConnect
  • Back: Synonyms panel. Front (optional): Known (unsuspended) + Total counts
  • Configurable meaning delimiters (; , | / ； 、 + Extra) so happy, glad splits into separate senses
  • Ignores filler gloss keys (etc, sth, sb, dictionary shorthand) so they do not create false synonyms
  • Click a synonym → open that note in the Browser
  • Tools → Chinese Word Synonyms… — decks, fields, delimiters, limits, colors, custom CSS
  • Works alongside Chinese Character Relations

Requirements

  • Anki Desktop 23.10+ (macOS, Windows, or Linux)
  • Notes with a Word/Hanzi field and a Meaning (or Definition / English) field

Setup

  1. Install and restart Anki
  2. Tools → Chinese Word Synonyms…
  3. General: set Word + Meaning fields, check Meaning delimiters → Rebuild Index
  4. Review a card whose meaning matches another note
